# Carpeta de imágenes

Pon aquí tus imágenes usando los nombres que ya están referenciados en la web:

- hero.jpg
- foto-1.jpg
- foto-2.jpg
- foto-3.jpg
- foto-4.jpg

Si quieres usar otros nombres, solo tienes que cambiar las rutas en [index.html](../../index.html).

Recomendación:
- usa imágenes en formato JPG o WebP
- tamaño recomendado: 1600px de ancho para la portada y 1200px para la galería
- conserva un estilo homogéneo para que la web tenga un aspecto más profesional
